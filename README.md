# godot-node-usage-auditor

A Godot editor plugin that scans the project for unused nodes and duplicate node names to help clean up scenes.

## Stack

Primary language: **GDScript**

## Project structure

- `addons/node_usage_auditor/auditor.gd` — Analyzes loaded scenes to report orphaned nodes and naming conflicts.
- `addons/node_usage_auditor/plugin.cfg` — plugin metadata

## Usage

Review the source files and install any dependencies referenced by the project before running it.
